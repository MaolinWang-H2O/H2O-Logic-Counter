## 0. Why This Tool / 为什么需要这个提纯器

*After a month at a logistics hub, I noticed something: everyone was busy, but the time actually spent on real output was less than one-third. 在快递站蹲了一个月之后，我发现一个现象：兄弟们每天都在忙，从早忙到晚，但真正在"干活"的时间，可能不到三分之一。剩下的时间，消耗在等货、找货、重复沟通、来回返工上。这不是人的问题，是流程的问题。文字也一样——大多数文案看起来很满，其实没多少干货。

*I distilled this into a tool: it does not tell you "write faster." It tells you **"where the water is."***

我把它做成了这个工具：它不告诉你"写快点"，它告诉你**"水分在哪里"**。

## 2. Six Dimensions / 六维度量（清醒温度计）

The engine scores your text on six dimensions, each 0–100:

引擎从六个维度给文本打分，每项 0–100：

| Dimension / 维度 | Question it answers / 回答的问题 |
|:---|:---|
| **清晰度 Clarity** | Is it unambiguous and actionable? / 表述是否无歧义、可执行？ |
| **一致性 Consistency** | Is it internally self-consistent? / 内部是否自洽、有无矛盾？ |
| **可追溯 Traceability** | Can every claim be traced to a source? / 能否追踪到源头依据？ |
| **可执行 Actionability** | Does it give a concrete instruction? / 是否给出明确动作指令？ |
| **爱与责任 Heart** | Does it show care for people? / 是否体现对人的关怀？ |
| **真诚与感恩 Origin** | Does it keep an honest baseline? / 是否守住真诚底色？ |

*The average of the six becomes the Logic Concentration score; weak dimensions (<50) trigger tailored advice.*

六项平均分即"逻辑浓度"总分；低于 50 的短板维度会触发针对性建议。

## 3. Grading Scale / 四档分级

| Score / 分数 | Tier / 档位 | Meaning / 含义 |
|:---|:---|:---|
| ≤ 35 | 🧊 **Ice / 冰态** | *Logic frozen, hollow claims* / 逻辑稀薄，虚假夸张 |
| 36 – 60 | 💧 **Water / 水态** | *Framework exists, needs polish* / 有框架，需润色 |
| 61 – 75 | ☁️ **Vapor / 气态** | *Self-cleaning logic, executable* / 逻辑自洁，可执行 |
| > 75 | ⭐ **Super / 超浓** | *Axiom-level, write it into the constitution* / 公理级，可写入宪法 |

*The displayed score is capped by the water rate, so a text full of hype can never score high no matter how polished it looks.*

显示分受"水分率"钳制——水分高的文本再顺眼也打不高。
